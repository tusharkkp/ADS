# Advanced Data Structures Lab (ADS)

This repository contains all practical programs implemented for the **Advanced Data Structures Lab** course of **Second Year B.Tech Computer Engineering** at **MIT Academy of Engineering**.

The programs are written in **C++** and cover important advanced data structures and algorithms such as:

* Binary Search Trees (BST)
* Threaded Binary Trees (TBT)
* AVL Trees
* Minimum Spanning Tree Algorithms
* Heap Sort
* Probabilistic Data Structures

# 🧠 Practicals Covered

## Practical 01 — Binary Search Tree

Implemented operations:

* Create BST
* Insert node
* Delete node
* Recursive traversals

  * Inorder
  * Preorder
  * Postorder
* Non-recursive traversals
* Level-wise printing

---

## Practical 02 — Threaded Binary Tree

Implemented operations:

* Create Threaded Binary Tree
* Inorder traversal
* Preorder traversal
* Postorder traversal
* Recursive and non-recursive traversal operations

---

## Practical 03 — AVL Tree

Implemented operations:

* AVL insertion
* Tree balancing using rotations
* Left Rotation
* Right Rotation
* Recursive traversals
* Non-recursive traversals

---

## Practical 04 — Minimum Spanning Tree

### Algorithms Implemented

* Prim’s Algorithm
* Kruskal’s Algorithm

Concepts Covered:

* Greedy Algorithms
* Weighted Graphs
* Disjoint Sets
* Cycle Detection

## Practical 05 — Heap Sort

Implemented:
